# Угадай назначение предмета

## Краткое описание ПО

Игровое приложение зала находок музея «Уткина дача». Посетитель по изображению предмета выбирает, для чего он был сделан, получает историческую справку после ответа и в конце видит общий результат. Доступен каталог находок.

## Сценарий работы ПО

### Стартовый экран

Заголовок «Угадай» / «для чего сделан предмет?». Кнопка **Начать игру**.

### Игра

Изображение предмета и варианты ответа из данных предмета.

### Экран результата ответа

- **Правильно!** или **Неправильно**
- правильный ответ и блок **Историческая справка**
- **Следующий предмет** — продолжить игру
- **Перейти к каталогу** — каталог находок
- при наличии — **Найти похожие находки**

### Финал

Экран «Игра завершена!» со счётом («Вы угадали X из Y предметов»). Кнопки:

- **Играть снова**
- **Перейти к каталогу находок**

### Служебный режим

Сочетание **Ctrl+Shift+A** открывает админ-панель.
